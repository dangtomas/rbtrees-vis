Visualizer usage guide

For the IB002 course, select Single tree variant in the top right corner and choose Classic RB Trees. The cases are identical as presented in the lecture.

The visualiser operates in two main states:

  1. Waiting for an operation

    • This is the default state when the visualizer starts.
    • In this state, you can either Insert or Delete an element identified by integer key. After selecting an operation, the visualiser transitions to the Operation in progress state.

  2. Operation in progress

    • The selected operation is now actively being executed and visualized.
    • In the top bar, the operation can be processed step by step in both directions.
    • Each step is accompanied by explanations and animations.
    • The element affected by the current action is marked with x.
    • The operation can be concluded using the Finish operation button. The visualizer then returns to the Waiting for an operation state.

The canvases on which the trees are displayed can be panned and zoomed. When an element is inserted or deleted, the operation is performed on all tree variants, and they can be switched between at any time. The tool also supports a side-to-side mode, allowing two tree variants to be displayed next to each other, making it easy to compare individual operations as they are performed.

Other settings and options:

  • Reset trees – Deletes the current tree, returns to Waiting for an operation state.
  • Generate random – Generates a random tree with 15 elements.
  • Fit trees – Adjusts the canvas so that the entire tree is visible and centered.
  • Show leaves – Toggles the visibility of NIL nodes. It is recommended to keep this option enabled for easier understanding of individual steps.
  • Auto-fit trees – Automatically applies the Fit trees functionality after each operation step.
  • Enable rotate animation – Determines whether rotation animations are performed during specific operation steps.
  • Export/import tree – Allows to export/import trees through .txt files, where each line contains a pair OPERATION-KEY.
